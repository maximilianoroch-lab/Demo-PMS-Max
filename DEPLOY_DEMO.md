# Deploy — Demo PMS Max

1. Crear un repositorio separado para la demo.
2. Subir el contenido de esta carpeta.
3. Crear una app Streamlit separada (sugerencia de URL: demo-pms-max).
4. En Streamlit Secrets cargar:
   OPENAI_API_KEY = "..."
   OPENAI_MODEL = "gpt-5.6"
5. Opcional:
   DEMO_ACCESS_CODE = "un-codigo"
6. No mezclar este deploy con PMS Max productivo.
